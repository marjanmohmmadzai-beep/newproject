
# MyPatientHUB

A responsive healthcare frontend project.

## Pages

- index.html - Login Page
- dashboard.html - Dashboard
- doctors.html - Find Doctor
- clinics.html - Find Clinic
- style.css - Complete styling
- script.js - JavaScript functionality

## How to Run

1. Create a folder named MyPatientHUB.
2. Save all files inside the folder.
3. Open index.html in your browser.

## Features

- Responsive Login Page
- Dashboard Statistics
- Doctor Search
- Clinic Search
- Sidebar Navigation
- Charts

## Note

This is a frontend demo.

Real authentication, database,
appointments, maps, and chat require
backend integration.
